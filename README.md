# Диапазон FM — «Диапазон ОС»

Одностраничное интернет-радио виде десктопной операционной системы: окна, панель задач, «Пуск», загрузчик, настоящая терминальная ОС. Русский интерфейс, чистый JS, **без сборки и без зависимостей**.

## Зачем один файл

Вся ценность проекта — перенос кода через ctrl+c / ctrl+v. Всё живёт в **`index.html`**, поэтому важно количество строк и отсутствие внешних файлов. Не разбивать, не выносить CSS/JS, не подключать библиотеки.

## Архитектура внутри одного `<script>`

Сверху вниз (ищи по маркерам `/* ================= ... ================= */`):

1. **Утилиты** — `$`/`$$`, `esc()`, `toast()`, `beep()` (WebAudio-бипы open/close/toast/err), тумблер `state.snd`.
2. **STORE** — `LSKEY='dipfm3'`, `freshState`, `load()` с миграциями, `save()` (debounce 2с) → `flushSave()`. Поля state: `v, snd, vol, theme, accent, f, q, last, current, playing, side, cover, fx, fxKind, fav{}, hist[], user[], listen{}, arts{}, wins{}, desk{}, alive, cruise`.
3. **DATA** — 38 станций `STATIONS`, `allStations()` = + `state.user`, `findSt()`, `freqOf()`.
4. **GLOB** — RadioBrowser-поиск (необязателен на стороне клиента).
5. **ENGINE / PLAY / META** — Audio, `playSt()`, `togglePlay()`, `step()`, `setVol()`, `pollMeta()` (12с), оффлайн-сторож.
6. **UI** — `renderFilters/renderHist/renderTop/renderCards/curSt/paintAll`.
7. **COVERS (скины)** — `const COVERS = [['','Классика'],['day'],['w10'],['w7'],['mac'],['cli']]`; `applyCover(c)` ставит `html[data-cover=...]` и вызывает `cliSync()`. CSS скинов — блоки `html[data-cover=...]` до `</style>`.
8. **СТАРТ** — deep-link `?st=`, первый визит → `#setup`; иначе `grubOpen(true)`.
9. **GRUB** — меню загрузки (см. ниже).
10. **CLI** — настоящий терминал (см. ниже).
11. **MC** — двухпанельный навигатор внутри терминала.
12. **WM** — окна: `WINDEF`, `wOpen/wHide/wToggle/wFocus`, taskbar `z 2000`, `#startMenu z 2001`, drag за `.winbar`, ресайз за `.resz`, память в `state.wins`.
13. **Фоны** — `state.fxKind`: fluid (WebGL), rain, paper, day.

## Скины ОС (data-cover)

Механизм один для всего: профиль, экспорт, миграция — бесплатно. `html[data-cover="…"]` в CSS; скин может задавать свои CSS-переменные (`--accent` и др.) и фон `body` (фон отдельно: `state.fxKind`, `#fxRow` в «Персонализации»).

- `''` Классика — дефолтный тёмный дизайн проекта
- `day` День — светлая тема
- `w10` Windows 10/11 — Mica-фон, акриловая панель по центру (Win11), квадратный логотип-«Пуск», единый плоский тайтлбар, красный крестик на ховере
- `w7` Windows 7 — Aero: тёмно-синие обои с заревом, стекло в рамках окон, круглый орб «Пуск», стеклянная панель задач, глянцевые кнопки
- `mac` macOS — обои Sonoma, тёмная строка меню сверху (body::before), плавающий стеклянный док с точками открытых окон, светофор-окружности, шрифт SF
- `cli` CLI — полноэкранный настоящий терминал (всё остальное прячется)

## GRUB-меню загрузки

- Показывается при **каждой загрузке страницы**, кроме первого визита (там `#setup`) и deep-link `?st=`.
- Открыть в любой момент: **F8**, **Shift+F2**, Пуск → «⏻ Перезагрузка · GRUB · F8», команда `reboot` в терминале.
- Пункты: Классика, День, Windows 10/11, Windows 7 Aero, macOS, radio-shell (CLI), Персонализация, Перезагрузка.
- Клавиши: `↑/↓` выбор, `Enter` загрузка, `Esc` продолжить без изменений; клик мышью тоже работает.
- Таймер автозагрузки 5 с, дефолт — текущий скин; стрелки его останавливают. Последний выбор — LS-ключ `dipfm3boot`.
- z-index: 3560 (выше терминала 3550, ниже сканлайнов cli-скина 3600).

## Терминал (radio-shell)

- Открыть/закрыть: **F2**, Ctrl+` `, «▸ Терминал · F2» в Пуске; cli-скин держит его поднятым.
- Login-сессия (`login: radio`), 30 команд: help, ls, cd, pwd, cat, play, pause, next, prev, vol, search, fav, unfav, top, hist, skin, fx, theme, clear, motd, gui, exit, echo, date, whoami, uname, np, add, mc, reboot.
- Вирт-ФС: `~` → каталоги `/stations /fav /user /hist` (файлы — волны `*.fm`), Tab-дополнение, история ↑/↓, Ctrl+C/L.
- `mc` — Midnight FM-Commander: две панели (листинг слева, состояние справа), `Tab/←→` папки, `↑↓` выбор, `Enter` играть, `f` ★, `q/Esc` выход.

## Золотые правила для агентов (рабочий цикл)

1. Правки `index.html` — **python-скриптами** в `/tmp`: `rep(old,new,cnt)` c assert на число вхождений; ничего не пишется, пока все assert не прошли (запись — один раз в конце). Regex-бекслеши в патчах экранировать по одному и проверять `od -c`.
2. Верификация перед деплоем — всегда: 
   - извлечь `<script>` → `node --check`;
   - python `HTMLParser` — баланс тегов (VOID: meta, link, br, img, input, hr, source, track, wbr, area, base, col, embed, param);
   - `grep -cP '[\x{0600}-\x{06FF}]' index.html` → 0 (rc=1 — норма);
   - jsdom-смок: `cp index.html /tmp/v400.html && cd /tmp/smoke && node desk40.js` → цель `SMOKE OK` (85+ проверок; окружение — `npm install jsdom` в `/tmp/smoke`).
3. Коммиты — только `git commit -F /tmp/cmsg.txt` (HEREDOC), никогда inline. Без force-push. Ветка `vibe/desktop-145b86`, PR #2 (draft).
4. jsdom-нюансы: `offsetLeft/offsetWidth` всегда 0 (расчёты drag/resize — от нулей); `document` смока — глобальный, window — `w`; Audio-стаб нужен (`play→resolve`, error через 30ms).
5. Проверенные ловушки эмодзи в патчах: 🖼 U+1F5BC, 📼 U+1F4FC, 📊 U+1F4CA, 🌐 U+1F310, 🎨 U+1F3A8.
6. Отчёты везде на русском.
